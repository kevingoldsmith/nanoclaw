**Architecture:** Prompt-only skill in `skills_for_nanoclaw/trip-map/`. The agent uses existing `drive_account2` MCP tools to create a Google Sheet in a "Trip Maps" folder. The `travel-recs` skill is updated to reference `trip-map` as a final step.

- [ ] **Step 2: Write SKILL.md**

Create `skills_for_nanoclaw/trip-map/SKILL.md` with the following content:

```markdown
# Trip Map

After recommending places for a trip, create a Google Sheet with map pins that the user can import into Google My Maps.

## When to Use

Use this automatically whenever you have recommended specific places (restaurants, stores, photography spots, attractions, etc.) during trip planning. Do not wait for the user to ask — create the map as a final step.

## Steps

### 1. Collect Places

From the recommendations you just gave, extract each place with:
- **Name**: The place name
- **Address**: Full street address, or landmark/area name if no street address (e.g., "Shibuya Crossing, Tokyo"). Google My Maps can geocode both.
- **Description**: One-line note about the place (e.g., "Highly rated vegetarian ramen, try the miso")

### 2. Find or Create the "Trip Maps" Folder

Use `mcp__drive_account2__search` to look for a folder named "Trip Maps".
- If found, note its folder ID
- If not found, use `mcp__drive_account2__createFolder` to create it

### 3. Check for Existing Sheet

Use `mcp__drive_account2__search` to look for a sheet matching the trip name in the "Trip Maps" folder.
- If found (e.g., updating with new recommendations), use `mcp__drive_account2__deleteItem` to remove it before creating a fresh one

### 4. Create the Google Sheet

Use `mcp__drive_account2__createGoogleSheet` to create a sheet named `{Destination} {Month Year}` (e.g., "Tokyo June 2026") in the "Trip Maps" folder.

For multi-city trips, use the broader region (e.g., "Japan June 2026").

### 5. Add Data

Use `mcp__drive_account2__appendSpreadsheetRows` to add:
1. Header row: Name, Address, Description
2. One row per place

### 6. Tell the User

Send a message like:

> Created "Tokyo June 2026" with 12 places in Trip Maps on Google Drive. To view on your phone:
> 1. Open Google My Maps (mymaps.google.com)
> 2. Create New Map → Import
> 3. Select from Google Drive → Trip Maps → Tokyo June 2026

### Fallback

If any Drive operation fails (auth error, MCP timeout, etc.), paste the places as a formatted table directly in the chat so the user can add them manually. Do not silently skip the map.
```
